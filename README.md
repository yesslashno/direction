# Direction

A clickable prototype for discovering a client's creative preferences before design work begins.

## Preview

Open `index.html` in a browser, or serve this folder with a local HTTP server. No dependencies or build step are required.

## Current experience

- Name and optional role
- A dedicated introduction to gut reactions
- 12 creative examples with swipe, tap, keyboard, undo, and enlargement controls
- A dedicated introduction to a closer look
- Six follow-ups with brand fit and multiple reason selections
- A fictional three-stakeholder report with an editable takeaway and stakeholder inclusion controls

## Prototype boundaries

Creative layouts and report responses are fictional. Client responses remain in memory for the current browser tab; they are not sent to a server. The report demonstrates the intended output using sample responses rather than submitted answers.

## Next development step

Test with a varied collection of real creative assets, then add client sessions, durable responses, and a report calculated from real stakeholder inputs.
